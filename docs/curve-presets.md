# 一键曲线样式与模板

## 操作方式

1. 在 AE 选中带关键帧的图层，通过 Window 菜单的 **DalimaoCurves** 或已绑定的快捷键打开面板。
2. 在顶部选择属性。面板下方的 **编辑段落 1 → 2** 明确指出目标相邻关键帧；用左右箭头切换段落，图中蓝色背景标示当前段。
3. 用 **模板编辑轴** 选择数值维度。普通多维属性只调整所选轴的缓动速度和影响；空间位置的时间缓动由各轴共用，按钮显示 **空间速度（共用）**。
4. 点击预设，立即修改左端关键帧的出侧和右端关键帧的入侧。预设不移动关键帧，不改关键帧值，也不改空间路径控制点。
5. 调整出满意的曲线后，点 **保存当前段**。模板自动命名为 `Curve 001` 等；在模板栏用左右箭头选择，点 **应用模板** 复用。支持删除和从磁盘重载模板库。

点击图中关键帧时，默认以该关键帧为段落左端，最后一个关键帧对应最后一段；拖入侧手柄时对应前一段。始终以工具栏显示的段落和编辑轴为准。本功能不推测鼠标在 AE Timeline 中的语义，也不批量处理所有图层。

## 内置样式

| 名称 | 左帧出侧影响 | 右帧入侧影响 | 端点速度 |
| --- | --- | --- | --- |
| 线性 | 使用线性插值 | 使用线性插值 | 由 AE 计算 |
| 标准缓动 | 33.333% | 33.333% | 0 |
| 左长右短 | 100% | 0.1% | 0 |
| 左短右长 | 0.1% | 100% | 0 |
| 双侧强缓动 | 66.666% | 66.666% | 0 |
| 双侧最长 | 100% | 100% | 0 |

这里的左右指时间顺序中左关键帧的出侧、右关键帧的入侧，避免“缓入/缓出”的命名歧义。模板模型使用百分数；写入 AEGP 时转换成 SDK 的 0–1 影响值，双侧最长保留为 `1.0 / 1.0`。

产品交互参考 [Flow](https://aescripts.com/flow/) 的曲线预设库和 [EaseCopy](https://aescripts.com/easecopy/) 的仅复用缓动方式，没有引入这些产品的代码或素材。标准缓动的零速和约 33.33% 影响参考 [Adobe 速度控制文档](https://helpx.adobe.com/after-effects/desktop/animate-in-after-effects/speed-between-keyframes/speed.html)。

## 模板内容与持久化

模板保存两端的时间插值类型、影响和归一化速度，不保存原始关键帧时间、数值或图层引用。

- 标量/非空间维度：`归一化速度 = 原速度 × 原段时长 / 原值差`。应用时按新值差和新时长换算，支持反向数值变化。
- 空间位置：以关键帧值和空间切线形成的三次贝塞尔路径弧长作为运动距离；路径长度由自适应细分求得。使用图层时间计算速度比例，以适配正时间伸缩。
- 零值差且非零速度的标量曲线无法定义稳定的归一化形状，保存时会明确拒绝。零值差的零速缓动可以保存和应用。
- 含游走关键帧的属性和负时间伸缩图层暂不处理，以避免改动曲线时连带移动关键帧。

模板文件位于 `%APPDATA%\DalimaoCurves\curve_presets.txt`，最多 100 个，重启 AE 后仍保留。文件采用带版本号的文本格式，完整验证后载入；损坏文件不会被自动覆盖。写入时使用锁文件、旧内容校验、临时文件和替换操作，避免多个 AE 实例互相覆盖。可点击 **重载** 读取外部更新。

## 撤销与边界

每次预设/模板应用是一个 AE 撤销组。**关闭面板后按 Ctrl+Z** 可撤销本次应用；模板库的保存/删除属于用户文件操作，不属于 AE 工程撤销。

为让两个端点的手柄独立工作，应用会关闭这两个关键帧的“自动时间贝塞尔”和“连续时间贝塞尔”标志。AE 的插值类型属于整个关键帧；多维属性的其他维度缓动数据会保留，但切换线性/贝塞尔类型可能影响同一关键帧其他维度的求值方式。空间属性的时间缓动本身也是共用的。

读取失败时不写入。写入失败或 AE 回读与预期不符时尝试恢复两端原缓动及标志；恢复失败会明确提示在 AE 撤销。时间、数值、其他侧的贝塞尔缓动会在写入后核对。

## 验证入口

```powershell
py deploy.py --build-only
powershell -NoProfile -ExecutionPolicy Bypass -File tests/run-tests.ps1
```

手工验证建议：

1. 用两帧标量属性依次点击六种预设，在 AE 关键帧速度对话框中核对影响值，重点检查 100/0.1、0.1/100、100/100。
2. 调整一端速度为非零，保存模板；应用到不同值差、不同时间跨度的两帧，再反向值差验证形状。
3. 关闭并重开面板、重启 AE，确认模板仍存在。
4. 使用三个以上关键帧，切换中间段落，确认关键帧时间和值、相邻段另一侧缓动未被改动。
5. 检查位置/缩放/分离维度、零值差、游走属性、撤销和保存失败提示。

纯模型和模拟 AE 测试不能代替宿主内视觉验收；实际 AE 行为以本机验证结果和用户试用为准。
