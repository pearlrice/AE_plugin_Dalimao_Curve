# AE 原生曲线版本

## 交互与兼容范围

Window → DalimaoCurves 命令打开 AE 自带的图形编辑器，并显示可同时操作 AE 的 Win32 工具窗口。再次执行命令会返回图层滑条。原来的 GDI+ 曲线绘制、像素标尺校准、鼠标移出关闭和阻塞消息循环已移除。

工具提供属性/两帧段落/维度选择、六个曲线样式按钮、两个影响滑块和模板库。选择属性时也请求 AE 选中对应属性，以便原生编辑器显示曲线。滑块只调整手柄长度；曲线速度、关键帧时间和值仍可在 AE 原生编辑器中直接调整。

当前适配本机 Windows AE 2025（25.4）英文界面。AE 官方将 Shift+F3 定义为图形编辑器与图层条的切换键：[Adobe 关键帧编辑说明](https://helpx.adobe.com/mena_en/after-effects/desktop/animate-in-after-effects/animation-keyframes/editing-moving-copying-keyframes.html)。该键需要保留给 AE；插件可以绑定 `4` 等其他键。插件检测到自身通过 Shift+F3 呼出时会提示更换绑定。

本机 UI Automation 暴露的时间轴名称为 `AE Timeline`，图形模式具有可见的 `Choose graph type and options` 和 `Auto-zoom graph height` 控件。当前实现依据这些状态，尚不声称支持其他界面语言。存在多个可见时间轴或读取状态不明确时停止切换并显示原因。

## 实现边界

- `DalimaoCurves.cpp`：标准 Win32 控件、快捷键接收、动作排队和 AEGP Idle/Command/Death 回调。窗口事件不调用 AE suites。
- `CurveStreams.inl`：逐次获取当前图层的数值属性。只在当前 AEGP 回调内保留 stream/value 资源，结束时释放。
- `CurvePresetPanel.inl`：模板持久化、端点缓动读写、撤销和失败恢复。文件名为兼容历史代码保留，已不包含自绘面板。
- `CurvePresetModel.h`：不依赖 AE 的曲线模板数学与序列化。
- `NativeGraphBridge.h`：独立 MTA 线程读 UI Automation、确认时间轴状态与焦点、执行原生切换并检查结果。不会在 AEGP 主线程中等待 UIA。

动作只携带合成 ID、图层 ID、当前 AE 会话的唯一属性 ID 和复制出的两帧数据。AE 忙碌时编辑控件暂时禁用；已经松开的滑块修改会先执行，然后处理关闭请求。应用前重新读取目标和端点；目标消失、时间/值/缓动变化或读取失败会停止旧操作并刷新。

AE 在前台时每 0.5 秒同步当前目标的数据。更换图层需要点击“读取 AE 选择”。快速从原生编辑器修改后立即点击工具时，若尚未同步，可能提示本次未修改；刷新后再次操作即可。

打开/关闭是异步请求。检测已处于目标模式时不发送按键；否则确认 AE 前台、时间轴焦点和修饰键释放，再发送一次 Shift+F3，随后检查模式。失败时保留工具窗口和错误提示，允许重试，不自动重复发送切换键。

## 验证

```powershell
py deploy.py --build-only
powershell -NoProfile -ExecutionPolicy Bypass -File tests/run-tests.ps1
py deploy.py --verify
```

自动测试覆盖预设数学、模板文件冲突/锁、端点与维度保留、撤销组、失败回滚、游走拒绝、滑块对零值差非零速度的保留以及过期关键帧快照拒绝。宿主内的焦点、键盘配置和界面状态需要单独实测。

手工验收：

1. 从图层条按自定义快捷键，确认出现原生图形编辑器和工具窗口；再次按键恢复图层条。
2. 预先打开原生图形编辑器，再呼出工具，确认曲线不会被关闭。
3. 在工具的按钮、属性下拉框和滑块获得焦点时，检查同一快捷键与 Esc。
4. 依次应用不对称、双侧最长预设；检查两个滑块、Ctrl+Z、模板保存和重开。
5. 修改原生曲线后等待同步再调整滑块；在 AE 更换图层或删除关键帧后确认不会误改旧对象。
6. 检查鼠标移出仍能继续操作 AE，长按快捷键不会来回开关。

- 只读宿主探测确认本机 AE 25.4 的原生图形编辑器、可见时间轴及图形模式控件；尚未验证图层条反向切换或新版控件交互。
